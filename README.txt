# TriLink Production Clean Kit

Thank you for using the TriLink Master Kit!

## 📦 What's Included
- Clean source code (no .git, no .next, no node_modules)
- All essential pages and components
- Public assets and global styles

## 🚀 How to Deploy
1. Navigate to the project folder:
   cd TriLink_Prod_Clean

2. Install dependencies:
   npm install

3. Build the project:
   npm run build

4. Start the app locally:
   npm start

5. Or deploy on Vercel, Netlify, Render, etc.

## 🛠 Requirements
- Node.js v18+
- npm v9+ (or use pnpm if preferred)

## 🔒 Notes
- Place your secrets in `.env.local`
- This version is safe for production and sharing.

Happy coding!
